# Project Summary — Customer Support QA & Bug Triage Lab

## One-line explanation

A portfolio lab that simulates how a SaaS support team turns customer reports into reproducible technical evidence, prioritized defects, engineering escalations, and clear customer communication.

## Scope

- 20 fictional support tickets
- 9 confirmed product defects
- 4 user/configuration issues
- 3 feature requests
- 2 unable-to-reproduce cases
- 2 service incidents
- 11 engineering/incident escalations
- 4 High/Critical product defects

## Why this project matters

Support and QA overlap heavily in real SaaS operations. A customer rarely reports a perfectly written bug. The work is to extract the useful facts, reproduce the issue, classify it correctly, assess impact, and provide engineering with evidence that is actionable.

This project demonstrates that workflow from end to end.

## Key examples

- Password-reset loop blocking account access
- Duplicate subscription charge after payment retry
- Mobile layout defect hiding a required action
- Authorization bypass exposing restricted billing details
- Service-wide latency and API incidents
- Configuration cases solved without engineering escalation

## Skills demonstrated

Technical Support, Manual QA, troubleshooting, defect reproduction, bug reporting, severity/priority assessment, incident triage, customer communication, engineering handoff, retesting, SaaS operations.
